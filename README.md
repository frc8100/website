# Website
The code and documentation for the team website.

# Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
    npm run dev
    ```
3. Open your browser and navigate to `http://localhost:3000` to view the website.
